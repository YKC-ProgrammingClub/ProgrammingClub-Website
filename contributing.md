# Contributing to Programming Club Website
Welcome! Whether this is your first time using Git or you already code regularly, here is how we work together:

1. Read `documentation/development-docs/gitworkflow.md`, `commitconventions.md`, and `codingstandards.md`.
2. Pick an assigned task or GitHub Issue (or ask if you need a task).
3. Create a branch from `main` **(never push directly to `main`)**.
4. Make small, focused commits using our commit message format.
5. Open a Pull Request on GitHub when your task is ready for review.

If you get stuck with Git, CSS, or JS, ask in the club chat or open an issue. Don't stay stuck for hours alone.
