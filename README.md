# ProgrammingClub-Website
Official website for our Programming Club, built with **HTML, CSS, and JavaScript** and hosted on **GitHub Pages**.

## What's Included
- **Homepage / Index:** Club overview, purpose, activities, and highlights.
- **Project Showcase:** Filterable gallery of club projects (including active/in-progress projects alongside completed ones) with live demos, GitHub links, tags, and contributors.
- **Member Directory:** Member profile cards with role, favorite languages, short bio, GitHub link, and avatar.
- **Starter Resources & Wiki:** Setup guides, beginner tutorials, learning links, and club Git workflow notes.
- **Join Us:** Application form for prospective members (name, contact info, experience, interests/motivation) wired to a form/notification endpoint.
- **FAQ:** Answers to common questions about joining, meetings, languages, and projects.

## Getting Started Locally
   in bash shell:
   git clone https://github.com/YKC-ProgrammingClub/ProgrammingClub-Website.git
   cd ProgrammingClub-Website
