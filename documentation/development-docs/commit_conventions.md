# Commit Conventions

Use the format:
`<type>: <short description in lowercase imperative/present tense>`

## Allowed Types
- `feat:` — new feature or section
- `fix:` — bug fix
- `style:` — CSS, formatting, or visual styling (not logic)
- `docs:` — documentation or copy/content updates
- `refactor:` — restructuring code without changing behavior
- `test:` — tests or verification helpers
- `chore:` — config, setup, or maintenance tasks

## Examples
- `feat: add member profile card layout`
- `fix: align mobile navbar toggle`
- `style: adjust project card spacing`
- `docs: add beginner git setup guide`
- `chore: add editorconfig and gitignore`

Avoid vague messages like `"update"`, `"stuff"`, or `"fix bug"`.
