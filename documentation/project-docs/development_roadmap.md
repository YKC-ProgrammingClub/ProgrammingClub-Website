# Development Roadmap

## Phase 1: Foundation & Setup
- Finalize repo structure, `.gitignore`, `.editorconfig`, and core docs.
- Set up shared header, footer, color/typography variables, and navigation.
- Walk all members through cloning, branching, committing, and opening a PR.

## Phase 2: Core Content & Layout
- Build Homepage, FAQ, and Starter Resources & Wiki structure and content.
- Build Member Directory cards and Project Showcase cards (including `Completed` and `In Progress` status labels).

## Phase 3: Interactivity & Join Form
- Add JS filtering by category/technology/status on the Project Showcase.
- Connect the Join Us form to a working email notification endpoint and test validation/error states.

## Phase 4: Polish, QA & Launch
- Fix layout/responsive bugs across desktop and mobile viewports.
- Verify all links, images, and member consent items.
- Publish via GitHub Pages.
